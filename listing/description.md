**Draw the outline of a shape, curves and all, then pull it up into a solid. One tool, no plane-extrude-extrude.**

Shape Draw is a pen tool for modelling. Click out the outline you want, drag to make curved edges, close it, and move the mouse to give it height. You get a clean mesh with flat caps, crisp corners and smooth curved walls, ready to bevel.

### Features

- **Corners and curves in one outline**: click for a sharp corner, click and drag for a smooth curved point.
- **Quick rectangles and circles**: drag one out from corner to corner or from the centre, with Shift for a square and a typed radius for exact circles.
- **Draw on any surface**: click a face of another object and the shape starts on that face. The face is highlighted and a snap grid appears on it.
- **Precise when you need it**: grid snapping, live edge lengths in your scene's units, typed edge lengths and heights, Shift for 15° angles, and edges that lock onto the grid axis when nearly lined up.
- **Pull it up**: move the mouse to set the height, or type an exact number.
- **Attach to what you drew on**: parent to the object, join into it, or cut into it with a live boolean you can still move.
- **Tweak afterwards**: the redo panel changes height, bevel (with an *Only Free Edges* option that leaves the base sharp), mesh or curve output and curve smoothness.

### How to use

1. Pick **Draw Shape** in the 3D View toolbar (or Add > Draw Shape).
2. Click to place corners, drag to make curves. Click the first point (or press Enter) to close.
3. Move the mouse to set the height and click to finish.
4. Change anything in the redo panel at the bottom left.

| While drawing | |
| --- | --- |
| Click / drag | corner / curved point |
| Type a number | exact length for the next edge |
| Shift | lock to 15° steps |
| Ctrl | turn grid snapping off |
| Backspace | remove the last point |
| P / R / C | outline / rectangle / circle |
| Right-click / Esc | cancel |

| While extruding | |
| --- | --- |
| Move the mouse / type a number | height |
| Click / Enter | finish |
| Right-click | back to drawing |

Works in Blender 4.2 and newer.
